# Termia · Maps Editor

**내 서비스에서 도형을 보내고, 편집된 결과를 돌려받으세요.**

Termia 편집기는 웹서비스에서 새 창으로 열어 사용하는 도형 편집 도구입니다. 정해진 JSON 형식으로 도형을 보내면 사용자가 점·선·다각형을 편집할 수 있고, 편집을 완료하면 결과가 원래 서비스 페이지로 전달됩니다. 직접 그리기와 행정동·법정동 등 참고 경계를 이용한 편집을 지원합니다.

기존 지도가 있는 화면은 물론 관리자 화면이나 입력 폼에서도 연결할 수 있습니다. 서비스 페이지에 자바스크립트 코드를 추가할 수 있으면 됩니다. 일반 연동에는 이 저장소를 복제하거나 Termia 내부 코드를 수정할 필요가 없습니다.

## 두 화면이 데이터를 주고받습니다

| 용어                      | 뜻                                                                |
| ------------------------- | ----------------------------------------------------------------- |
| **서비스 페이지**         | 편집 창을 열고, 편집할 데이터를 보내며, 편집 결과를 받는 웹페이지 |
| **편집 창**               | 전달받은 도형을 편집하고, 완료된 결과를 서비스 페이지로 보내는 창 |
| **편집 데이터** (`scene`) | 편집할 도형 목록과 관련 설정을 담은 데이터 전체                   |

1. **열고 보내기:** 서비스 페이지에서 [편집기 주소](https://maps-editor.pages.dev/editor/)를 새 창으로 열고, 준비 완료 알림을 받으면 편집 데이터를 보냅니다.
2. **편집하기:** 사용자가 편집 창에서 도형을 만들거나 수정합니다.
3. **결과 받기:** 편집 완료 시 서비스 페이지가 전체 편집 결과를 받습니다. 받은 결과를 화면에 반영하거나 서비스 서버에 저장합니다.

**편집 완료는 결과를 보내는 동작입니다. 서버 저장은 서비스가 처리합니다.** 취소하면 편집 결과를 보내지 않으므로 서비스 페이지의 기존 데이터를 유지합니다.

HTTPS 사이트는 편집기와 도메인이 달라도 연결할 수 있습니다. HTTP·localhost에는 추가 허용 조건이 있으며, 연결 사이트를 제한한 배포는 해당 허용 목록을 따릅니다. 창 사이의 `postMessage` 통신을 사용하므로 주소만 직접 열면 데이터를 기다리는 화면이 표시됩니다. [주소와 연결 조건](docs/integration.md#편집기-주소와-연결-조건)을 먼저 확인하세요.
