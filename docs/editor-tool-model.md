# 에디터 도구·인터랙션 모델

최초 정리: 2026-05-31 · 현황 갱신: 2026-08-27

좌측 도구 rail, 선택·편집 상호작용, 레이어 스택과 history의 현재 구현 계약을 코드 기준으로 정리한 참조 문서다. 설계 논의의 원본은 이슈 #35이며, 사용자 조작 방법은 앱의 `/editing` 문서를 기준으로 한다.

## 1. 도구 rail과 활성화 정책

좌측 rail은 네 도구를 세로로 둔다. `activeMode`에서 파생한 `getToolActivation`이 OpenLayers interaction의 활성 여부를 한곳에서 결정한다.

| 도구   | 값         | 역할                                   | 하위 옵션                          |
| ------ | ---------- | -------------------------------------- | ---------------------------------- |
| 선택   | `select`   | 선택·정점 편집·이동·폴리곤 불리언 연산 | 없음(기본)                         |
| 그리기 | `draw`     | 새 피처 추가                           | 폴리곤 / 패스 / 마커               |
| 경계   | `boundary` | 외부 경계를 조회해 생성·병합·제거      | `region_kind`의 선택 가능 카탈로그 |
| 반경   | `radius`   | 마커 중심 원형 폴리곤 생성             | 반경 km 입력                       |

- 도구는 한 번에 하나만 활성화한다. 선택 상태는 모드가 바뀌어도 유지하지만, 해당 모드에서 허용하지 않는 interaction과 정점 오버레이는 즉시 끈다.
- 선택 도구는 선택·정점 편집·이동·불리언 연산을 모두 활성화한다.
- 반경 도구는 기준 마커를 고르기 위한 선택만 활성화한다. 정점 편집·이동·불리언 연산은 끈다.
- 그리기와 경계 도구에서는 기존 scene 선택 interaction을 끈다.
- 진행 중인 Draw sketch가 있을 때 도구나 그리기 도형을 바꾸면 먼저 취소 확인을 거친다.
- 반경을 적용하거나 취소하면 선택 도구로 돌아간다. 다른 도구는 사용자가 바꿀 때까지 유지된다.

## 2. 선택·이동·정점 편집

지도와 레이어 패널은 같은 `selectedFeatureIds`를 공유한다.

- 지도 일반 클릭은 최상단의 선택 가능한 도형 하나로 선택을 교체하고, 빈 곳 클릭은 전체 선택을 해제한다.
- `Cmd(macOS)/Ctrl(기타)+클릭`은 기존 선택에서 도형을 추가하거나 제거한다. 보조키로 빈 곳을 클릭하면 현재 선택을 유지한다.
- 레이어 행은 잠긴 참고 도형도 선택할 수 있다. 지도 일반 선택은 편집 가능하고 잠금 해제된 콘텐츠를 대상으로 하며, 반경 모드에서는 잠긴 마커도 별도 정책으로 선택할 수 있다.
- 보이고 잠금 해제된 편집 가능 도형이 정확히 하나 선택되면 정점 편집을 활성화한다. 별도의 더블클릭 편집 상태는 없다.
- 기존 정점 드래그는 이동, 외곽선 클릭은 정점 삽입, 정점 우클릭은 삭제다. 한 제스처를 scene history 한 단계로 커밋한다.
- 선택한 편집 가능 도형의 몸통은 `Cmd/Ctrl+드래그`할 때만 이동한다. 일반 드래그는 지도를 움직인다.
- 다중 선택에서는 정점 편집을 끄고, 선택된 항목 중 편집 가능한 도형 전체를 한 번에 이동할 수 있다. 한 번의 다중 이동도 undo 한 단계다.
- 잠김·숨김·읽기 전용 도형은 선택 하이라이트를 유지할 수 있지만 정점 편집과 이동 대상에서는 제외한다.

## 3. 그리기 = 새 피처 추가

그리기는 폴리곤·패스·마커를 새 피처로 만드는 하나의 도구다. 진행 중 sketch는 OpenLayers adapter가 소유하고, 완성된 geometry만 `addFeatures`로 scene에 커밋한다.

- Draw 정점은 보조키 없는 마우스 좌클릭 또는 터치·펜 primary pointer로만 추가한다. 우클릭·휠 클릭·macOS `Ctrl+클릭`은 입력으로 보지 않는다.
- 마커는 한 번 클릭하면 즉시 완성한다.
- 패스는 정점 2개 이상에서 하단 `패스 완료` 버튼 또는 `Enter`로 완성한다. 더블클릭으로 끝내지 않는다.
- 폴리곤은 서로 다른 정점 3개 이상에서 시작점을 다시 클릭하거나 하단 `폴리곤 닫기` 버튼 또는 `Enter`로 완성한다. 마지막 정점 재클릭은 완료로 보지 않는다.
- `Cmd/Ctrl+Z`와 redo는 진행 중 sketch의 정점 로컬 history를 먼저 사용한다. 완성 시에만 새 레이어와 전역 history 한 단계를 만든다.
- sketch 진행 중에는 copy/cut/paste를 차단한다. `Escape` 또는 도형·모드 전환은 취소 확인을 열며, 확인하면 sketch만 버리고 scene은 바꾸지 않는다.
- 키보드 사용자는 지도에 포커스를 두고 `K`로 조준 모드를 켠 뒤 방향키로 중심을 옮기고 `Space`로 정점을 추가한다. 같은 좌표의 중복 입력은 무시한다.

### 알려진 제약: 반복 월드 경도

OpenLayers View는 현재 가로 반복 월드를 제한하지 않는다. 반복 월드에서 그리면 GeoJSON 입력 schema의 경도 범위 `[-180, 180]` 밖 좌표가 만들어져 복사 또는 재INIT에서 거부될 수 있다. 실제 요구가 생기면 단일 월드 View 제한과 날짜변경선 횡단 geometry 정책을 함께 결정한다. Path/Polygon 좌표를 개별적으로 단순 wrap하지 않는다.

## 4. 반경 폴리곤

반경은 폴리곤을 자르는 도구가 아니라, 마커 한 개를 중심으로 지표면 거리 기준 원형 Polygon을 새로 만드는 도구다.

- 마커가 이미 하나 선택된 상태에서 반경 도구를 누르면 입력 팝업을 즉시 연다.
- 선택 없이 반경 도구를 누르면 마커 선택만 기다리고, 지도나 레이어에서 마커 한 개가 선택되면 팝업을 연다. 잠긴 마커도 기준점으로 허용한다.
- 입력은 `0.01–1,000km`, 소수점 이하 두 자리까지 허용한다. 입력 중 원은 별도 OpenLayers preview 레이어에만 표시하고 scene/history는 바꾸지 않는다.
- 적용하면 `@turf/circle`로 Polygon을 만들고, `반경 {값} km` 이름과 `radiusKm`, `radiusSourceFeatureId` properties를 붙여 최상단 새 레이어에 추가한다.
- 원호와 직선 변의 오차를 5m 이내로 맞추되 64–1,024 steps로 제한한다.
- 날짜변경선이나 극점을 지나는 결과는 현재 GeoJSON/OpenLayers 경계 정책과 맞지 않아 추가를 거부한다.
- 생성 전체를 전역 history 한 단계로 커밋한 뒤 선택 도구로 돌아가고 새 원을 선택한다.

## 5. 외부 경계 카탈로그

경계는 대용량 외부 데이터이므로 편집 scene이나 레이어 패널에 직접 쌓지 않는다.

- 종류·라벨·정렬은 서버 `region_kind`가 단일 출처다. 조회 실패 시 최소 KR fallback 카탈로그를 사용한다.
- `regions_by_view`가 현재 bbox와 zoom에 맞는 단순화 경계를 반환한다. `truncated`이면 확대 안내를 표시한다.
- 화면 표시용 경계는 scene 밖 OpenLayers 참고 레이어에 둔다. 연산 시에는 row id로 `region_by_id` 원본 geometry를 다시 가져온다.
- 선택 폴리곤이 없을 때 `+`는 경계를 새 편집 폴리곤으로 복사한다.
- 편집 가능한 폴리곤 하나가 선택되면 `+`는 원본 경계를 선택 도형에 union하고, 겹친 경우 `−`는 선택 도형에서 경계를 difference한다. 외부 카탈로그 원본은 항상 보존한다.
- 원본 조회 중 session·scene·선택이 바뀌면 오래된 비동기 연산 결과를 버린다. 진행 중에는 완료·취소 액션을 막는다.

## 6. 폴리곤 불리언 연산

선택 도구에서 편집 가능한 폴리곤 하나를 target으로 정하고, 화면 안의 다른 편집 가능한 폴리곤을 operand로 사용한다.

- `+` 병합은 모든 다른 폴리곤 후보에 표시한다. 떨어진 도형도 MultiPolygon union 결과가 가능하다.
- `−` 제거와 교집합 버튼은 실제 면적이 겹치는 후보에만 표시한다. bbox broad phase 뒤 Turf 면적 교차로 판정한다.
- 병합은 target geometry를 union 결과로 바꾸고 operand 피처를 제거한다.
- 제거는 target에서 겹친 부분을 빼고 cutter를 보존한다. 결과가 완전히 비면 target을 삭제 상태로 처리한다.
- 교집합은 target을 두 도형이 공유하는 면으로 바꾸고 operand를 보존한다.
- 각 연산은 원자적인 scene edit 한 번이며 undo 한 단계다. 선택 target은 연산 뒤에도 유지한다.
- 잠긴·숨김·읽기 전용 폴리곤은 현재 target과 peer operand에서 제외한다. 외부 경계만 별도의 복사 operand 정책을 사용한다.

## 7. 평탄 레이어 스택

내부 모델은 `EditorScene -> EditorLayer[] -> EditorFeature[]`를 유지하지만 운용은 `1레이어 = 1도형`인 평탄 스택이다. 공개 v2 입력의 `features`를 정규화할 때 도형마다 내부 레이어 하나를 만든다.

- 패널은 zIndex 내림차순으로 도형을 표시하며 맨 위 행이 지도에서도 가장 앞이다.
- 그리기·반경·경계 생성·붙여넣기로 만든 도형은 항상 현재 최상단에 추가한다.
- 눈 아이콘은 visibility를, 자물쇠는 lock을 바꾼다. 이 view/UI 액션은 history 스냅샷을 만들지 않는다.
- 이름 변경은 잠금 해제된 편집 가능 도형에 허용하며 앞뒤 공백을 제거한 1–100자로 검증한다. 이름은 부모 반환 데이터이므로 history에 기록한다.
- 삭제 버튼은 에디터에서 생성한 `Created` 도형 중 잠금 해제되고 삭제 가능한 항목에만 표시한다. 부모가 INIT으로 준 원본은 보호한다.
- 끌기 핸들 또는 핸들 포커스 후 `Space`+방향키로 zIndex 순서를 바꾼다.
- 선택 도형 복사·붙여넣기는 전용 JSON 포맷을 사용한다. id와 lock은 복사하지 않고, 새 id·잠금 해제 상태로 최상단에 추가하되 선택한 여러 도형의 상대 순서는 보존한다.

## 8. 상태·history·부모 반환

- Zustand store가 `sessionId`, `scene`, `activeMode`, 선택·호버, 이름 편집 상태, `past`/`future`, `dirty`를 소유한다. OpenLayers 객체와 진행 중 Draw sketch·반경 preview는 store에 넣지 않는다.
- geometry·이름·도형 추가/삭제·불리언 연산처럼 부모에게 반환되는 도메인 변경은 `commitSceneEdit`를 거쳐 scene 스냅샷을 쌓는다. 최대 50단계다.
- 선택·호버·모드·패널 위치·visibility·lock·zIndex 같은 UI/view 변경은 자체 history 스텝을 만들지 않는다. 다만 scene 스냅샷에 포함된 값은 다른 편집을 가로질러 undo할 때 그 시점 값으로 복원될 수 있다.
- `Cmd/Ctrl+Z`는 undo, `Cmd/Ctrl+Shift+Z`와 Windows `Ctrl+Y`는 redo다. 입력 필드와 확인 모달에서는 무시한다.
- 에디터는 편집 중간마다 `MAP_EDITOR_CHANGE`를 보내지 않는다. 사용자가 하단 `저장하고 완료`를 누르면 공개 `EditorSceneInput v2`를 `MAP_EDITOR_SUBMIT`으로 한 번 반환한다.
- 취소는 `MAP_EDITOR_CANCEL`만 반환하고 scene을 보내지 않는다. 그리기·반경 입력·경계 연산·이름 변경이 진행 중이거나 invalid 도형이 있으면 완료를 막는다.

## 9. 남은 고도화 항목

- geometry kind별 면적·길이·자기교차 등 제품 validation 정책
- 일반 readonly 도형을 불리언 operand로 쓸 수 있게 하는 세분화된 capability 모델
- 대량 scene에서 layer/feature diff sync와 style cache를 적용하는 렌더링 최적화
- 반복 월드와 날짜변경선 횡단 Path/Polygon 정책
- 지역 경계 데이터의 시도별 증분 적재·버전 운영 자동화
